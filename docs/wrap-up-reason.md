# Wrap-up reason and wrap-up timer for the Appointment / Billing Queue

We will use the below Wrap-up reasons for the Agent(s) to select for the Appointment / Billing queue

<p class="lab-step" markdown="1">• Billing Enquiry</p>

<p class="lab-step" markdown="1">• Appointment Schedule</p>

<p class="lab-step" markdown="1">• Insurance details</p>

<p class="lab-step" markdown="1">57. Go to Services &gt; Customer Assist &gt; Desktop Experience. Click on Add Wrap-up reason</p>

![Screenshot](./assets/image59.png)

<p class="lab-step" markdown="1">58. On the Add wrap-up reason page, Create the Wrap up reason Billing Enquiry then select Specific queue followed by the Appointment Billing Queue.  Click Create.</p>

![Screenshot](./assets/image60.png)

<p class="lab-step" markdown="1">59. You will be taken back to the Wrap-up Reasons page.  Click Manage followed by Add Wrap-up Reason.</p>

![Screenshot](./assets/image61.png)

<p class="lab-step" markdown="1">60. Add 2 more wrap up reasons, Appointment Schedule and Insurance details like how you added the first one</p>

<p class="lab-step" markdown="1">61. Next to Set a default wrap-up time for the support queue- Under the Services section on the left panel select Customer Assist &gt; Queues and select the Appointment Billing Queue as shown in the screenshot below</p>

![Screenshot](./assets/image62.png)<br>71. Go to Overview section and click Wrap-up reasons.

![Screenshot](./assets/image63.png)

<p class="lab-step" markdown="1">72. From here you can see the assigned wrap-up reasons and the default option (in this example, Billing Enquiry). Enable the Wrap-up timer and the timer to 01:00 (1 minute) and then click on Save.</p>

![Screenshot](./assets/image64.png)

Congratulations, now the Appointment / Billing queue is completed, it’s time to move onto the Nurse queue.
